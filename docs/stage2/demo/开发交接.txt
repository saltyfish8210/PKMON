三、技术边界
使用真实账号 Bearer 会话；关闭开发身份请求头。课堂允许模拟位置和模拟遭遇，仍需由驻留流程生成用于捕获的同一个 spawnId。
使用 dev 配置，任务与捕获均为 JDBC 持久化。区域从数据库 regions 表读取；dev 下不是修改经纬度启动参数就能覆盖该表。
课堂只覆盖候选区域与 SIMULATED 样本。真实设备接入需另外准备实际 WGS84 区域数据和真机验证。
课堂参数 required-seconds=4、cooldown-seconds=0 仅用于排练；常规默认仍为驻留 600 秒、冷却 1800 秒。
账户、数据文件不随源码提交；演示包中的 data 在运行后创建，重启不要删除。

四、继续开发从哪里开始
账号入口：client/lib/features/auth/app_gate.dart、client/lib/features/member_home_page.dart。
自习页面及协调：client/lib/features/study/；正式接口：client/lib/data/api/。
驻留与触发：server/src/main/java/edu/pkmon/study/。
题目、捕获、收藏：server/src/main/java/edu/pkmon/capture/。
数据库迁移：server/src/main/resources/db/migration/；不要改写已经应用的 V1—V3 文件，新变更新增迁移。
成品构建与验收：tools/demo/README.txt。

五、Git 使用
开始前先看 git status，确认所在分支和现有改动，避免覆盖其他人的工作。
完成的更改按明确文件路径提交。合入主线前读取最新 origin/main；如已前进，正常合并并复测受影响内容。
不用 force push、reset --hard 或 git clean 处理交付问题。展示包、运行时、视频和数据库不推入源码仓库。
最终代码提交与成品 SHA256 见同批版本清单。技术证据只记录本次实际执行结果，不将自动测试写成真机验收或其他成员的个人确认。
