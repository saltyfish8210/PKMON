PKMon 课堂演示使用说明

一、拿到演示包后
1. 将整个压缩包解压到本地文件夹，不要在压缩包预览窗口内直接运行。
2. 双击“启动演示.cmd”。完整 Windows x64 包自带 Java 运行环境，展示电脑只需已安装 Chrome 或 Edge；不需要 Flutter、Maven 或 Android SDK。
3. 程序准备好后会自动打开浏览器。若没有自动打开，复制启动窗口显示的 http://127.0.0.1:端口/ 地址。
4. 默认尝试 4191 端口；已被占用时自动改用空闲端口，不会停止其他服务。以本次启动窗口显示的地址为准。
5. 展示过程中保留启动窗口。结束时在该窗口按 Enter 停止本次服务。请勿同时启动同一文件夹中的两个副本。

二、第一次操作
1. 点击“注册新账号”。用户名用 3—24 位字母、数字或下划线，密码至少 12 位；昵称可以用中文。自行保存演示账号和密码，不要写入公开仓库。
2. 注册成功后点击“登录”。本次展示使用登录后的正式业务流程，不使用“进入演示（不登录）”的第一阶段游客原型。
3. 点击“进入自习任务”，再点“使用模拟位置开始”。等待约 12 秒：页面依次出现等待进入区域、驻留中、已出现精灵。
4. 点击“前往答题”，先选 B 展示错答重试，再选 A。看到“成为伙伴了！”后点击“查看收藏”。
5. 收藏页返回捕获结果，点“返回自习”，再点“结束任务”，返回首页。首页收藏数量应同步更新。
6. 关闭服务再启动，重新登录同一账号。收藏记录仍在；若上次任务未结束，进入自习任务后可恢复或结束该任务。

三、重复排练与数据
数据保存在演示包的 data 文件夹。退出账号、刷新网页、关闭服务都不应删除 data。
刷新或重新打开网页后需要重新登录；这不表示账号与收藏丢失。
课堂启动参数将有效驻留阈值设为 4 秒，任务冷却设为 0，便于重复排练。样本每 3 秒上传一次，阈值不等于实际等待时间。
同一账号结束任务后可以再次开始，累计捕获数会增加；同一次遭遇的重复提交不会重复计数。
如果要展示从 0 到 1，注册一个新的演示账号即可，不要清空旧数据库。

四、运行范围
本包监听本机 127.0.0.1，不需要公网服务器。网页、中文字体、界面图片和网页渲染资源随包提供。
账号、任务、驻留判定、题目与答案判定、收藏记录均由实际 Spring Boot 服务处理；账号、自习和捕获仓储使用 H2 文件数据库。
输入的地点来自课堂模拟位置，界面明确标注模拟。Android 真机权限弹窗、真实 GPS 与实际学校围栏尚未验收，不在本包已验证范围。
当前展示一种精灵“攻城狮”和一道 Hello World 题，不宣称题库、多精灵或真实校园地图已经完成。

五、遇到问题
浏览器打不开：先看启动窗口是否显示 ready 和访问地址；端口变化后使用新地址。
端口占用：启动器会换端口，无需查杀陌生进程。
数据库正在使用：检查是否已经启动同一演示包；回到原启动窗口按 Enter 后再启动。保留 data 文件夹。
收藏加载失败：确认本次启动窗口仍在运行，再点“重试”或重新登录。
长时间没有精灵：确认进入的是登录后的自习任务，使用模拟位置开始，并让页面保持前台。已有任务先恢复或结束，再开始新任务。
需要排查时保留 logs 文件夹中的日志；不要将密码、会话令牌或 data 数据库发到公开仓库。
