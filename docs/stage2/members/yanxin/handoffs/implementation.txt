启动与手工对接
1. 从包含上述提交的 main 运行，在仓库根目录执行 mvn -B -f server/pom.xml package，使用 Java 17。
2. 使用仓库根目录下的 server 作为工作目录，执行下面的命令。默认接口地址为 http://127.0.0.1:4180/api/v1。
   java -jar target/pkmon-server-0.1.0.jar --spring.profiles.active=dev --pkmon.capture.dev-user-header=false
   同一目录再次启动可读取相同的 dev 文件库。若换端口，给此命令增加 --server.port=4181，并同步客户端 API_BASE 的端口。
3. POST /auth/register，JSON 输入 username、password、nickname。用户名为3至24个 ASCII 字母、数字或下划线，统一按小写保存。密码12至64个Unicode码点、最长72个UTF-8字节。昵称去除首尾空白后1至20个码点。
4. POST /auth/login，JSON 输入 username、password。成功后将 data.token 放入后续请求的 Authorization: Bearer <token> 头。GET /users/me 应返回本人的 userId、username、nickname；POST /auth/logout 后，同一凭据访问 /users/me 应返回 HTTP 401 和业务码40101。
5. 实际成功与失败 JSON 样例在 ../evidence/implementation/http-results.txt。其他错误为非法输入 400/40001、用户名重复 409/40901、认证依赖暂不可用 503/50301。保存证据时遮掉密码与完整 token。
