课堂操作
登录 → 地图“任务模式” → 使用模拟位置开始 → 驻留达标 → 前往答题 → 答错后重试 → 答对收录 → 返回自习 → 结束任务。
账号入口使用统一 HTTP 客户端。自习页读取服务器的任务号、暂停原因、有效驻留时间和遭遇号。达到阈值后，同一个遭遇可用于正式挑战；成功创建记录后由服务端返回收藏数量。模拟课堂采用 dev 配置、关闭开发身份头，位置样本标记为 SIMULATED。演示包的全部操作已在 Chrome 中复验。
