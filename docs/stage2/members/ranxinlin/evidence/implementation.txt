二、真实联调（实际执行）
  后端构建：mvn -B -s <workspace>\.tools\maven-settings.xml -DskipTests package
    -> target/pkmon-server-0.1.0.jar（25.7 MB）
  启动：java -jar target\pkmon-server-0.1.0.jar --pkmon.capture.dev-spawn-enabled=true
    （默认内存 H2 + Flyway V1-V3；开发遭遇入口开启，身份走真实 Bearer）
  健康检查：GET /test/hello -> HTTP 200 "hello world"
  联调命令（client）：
    PKMON_REAL_BACKEND=1 flutter --no-version-check test test/integration/real_backend_test.dart
  结果：+3 All tests passed!
  覆盖场景：
    - 注册 -> 登录 -> GET /users/me 返回本人；
    - 无 token 的受保护请求 -> 40101 unauthorized；
    - POST /dev/spawns 创建遭遇 -> POST /capture/challenge 取题（选项 2..4，无答案字段）；
    - 错选项 -> WRONG、captureRecordId 为空；
    - 正确选项 -> CORRECT、captureRecordId 非空；
    - 同一 requestId 同内容重发 -> 返回同一 captureRecordId（幂等）；
    - 同一 requestId 不同内容 -> 40902 conflict；
    - GET /capture/challenges/{id} -> CAPTURED 且记录号一致；
    - GET /collection/summary -> captureCount >= 1。
  旧演示路由回归（HTTP 直调）：
    POST /demo/sessions -> /demo/explore -> /demo/capture/challenge -> /demo/capture/answer
    结果：challenge 返回“攻城狮”，answer success=true；确认 F2 路径修复有效。
