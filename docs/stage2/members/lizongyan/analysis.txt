本文件覆盖第二阶段两项核心功能的分析：①自习任务与精灵遭遇；②答题捕获与精灵收录。本人负责测试视角：需求到测试的对应关系、自动测试与完整功能测试。本阶段优先分析第二项“答题捕获与精灵收录”的真实完整流程；范围不含全面性能压测。

当前源码与实际能力：
已核对：通过阅读 README 与源码目录，确认存在 client/（Flutter前端）、server/（Spring Boot后端）、scripts/（一键构建脚本）。
实际运行与能力边界：
1. 环境配置：本机已成功配置 Java 17.0.20.1 与 Flutter 3.35.5。
2. 后端启动：在 server 目录下使用 Maven 打包并运行 java -jar，成功启动服务，监听 4180 端口。
3. 接口连通性：GET /test/hello 返回 "hello world"；POST /api/v1/demo/sessions 和 /explore 成功建立会话并返回 nearby=True。
4. 核心能力缺陷：前端 pubspec.yaml 限制 Dart SDK ^3.13.5，本地环境无法一键构建前端；官方 README 缺失取题接口的 `/demo` 层级路径，导致测试初期返回 401 未经授权（查源码后已修正并跑通）。

参与者和业务对象：
参与者：测试用户（通过 X-Demo-Session 模拟）。
业务对象：Session（演示会话）、Spawn（遭遇，如 library-001）、Challenge（题目）、CaptureRecord（捕获结果）。
状态：Challenge（OPEN/CAPTURED）、Demo State（count、captured、nearby）。

正常流程（已实测跑通）：
建立会话（POST /api/v1/demo/sessions）→ 探索（POST /api/v1/demo/explore）→ 获取题目（POST /api/v1/demo/capture/challenge，传入 library-001）→ 提交正确答案（POST /api/v1/demo/capture/answer，optionId=A）→ 查询状态（GET /api/v1/demo/state）成功返回 captured:True, count:1。

异常流程（已实测）：
1. 鉴权与路径异常：按 README 缺失 /demo 的路径请求取题，服务端返回 401 未经授权。修正路径后可正常跑通。
2. 无鉴权访问拦截：不携带 X-Demo-Session 请求探索接口，服务端正确拦截并返回 HTTP 400。
3. 非法参数拦截：传入非法 spawnId（如 invalid-999），服务端正确拦截并返回。
4. 答错题异常：提交错误选项 B 后，查询状态返回 captured=False, count=0，符合预期。
5. 越权访问（未执行）：由于演示版使用 X-Demo-Session 隔离，未包含跨用户资源访问 API，标记为未执行。
