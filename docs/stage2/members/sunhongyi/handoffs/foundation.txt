二、运行方式（真实可用）
  1) cd server
  2) mvn -B test                      → 预期 Tests run: 34，BUILD SUCCESS
  3) mvn -B package -DskipTests
  4) java -jar target/pkmon-server-0.1.0.jar --spring.profiles.active=dev
     （监听 127.0.0.1:4180。必须带 dev 或 test profile：2026-10-25 起开发期身份替身与
      开发遭遇入口默认关闭，无 profile 时业务接口一律返回 503/50301）
  5) 另开终端，正式业务接口需带开发期身份头 X-Dev-User: <任意用户标识>
     示例：
       curl -X POST http://127.0.0.1:4180/api/v1/dev/spawns \
         -H "Content-Type: application/json" -H "X-Dev-User: u-1" \
         -d '{"regionId":"library_entrance","speciesId":"siege_lion"}'
  6) 依次调用 /api/v1/capture/challenge、/api/v1/capture/answer、
     /api/v1/capture/challenges/{id}、/api/v1/collection/summary，
     字段与样例见 design/interfaces.json。
  三个开关（2026-10-25 起安全默认为关闭前两项）：
     pkmon.capture.dev-user-header    默认=false；dev/test profile 下默认 true（X-Dev-User 身份替身）
     pkmon.capture.dev-spawn-enabled  默认=false；dev/test profile 下默认 true（/dev/spawns）
     pkmon.capture.in-memory-store    默认=true（真实持久化接入前必须为 true，否则无仓储、起不来）
     显式覆盖示例：java -jar ... --pkmon.capture.dev-spawn-enabled=false
