二、演示路径（本人负责段）

用真实 HTTP 演示"任务 → 触发 → 出题"，不依赖客户端界面：

启动（开发服务器 group8）：
  java -jar target/pkmon-server-0.1.0.jar --spring.profiles.active=dev \
    --server.address=127.0.0.1 --server.port=4181 --pkmon.capture.dev-user-header=true \
    --pkmon.capture.in-memory-store=true --pkmon.study.in-memory-store=true \
    --pkmon.study.rules.required-seconds=5
