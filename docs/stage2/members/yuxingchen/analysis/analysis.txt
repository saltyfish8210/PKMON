一、目标与范围

1. 分析目标

本分析面向第二阶段的两个核心功能——“自习任务与精灵遭遇”“答题捕获与精灵收录”——中属于本人负责的账号入口与公共界面部分，回答四个问题：

（1）用户如何从打开 App 进入真实业务；
（2）登录态如何建立、保存、恢复、失效和清除；
（3）客户端主入口如何在不侵入各业务页面的前提下完成登录门禁和页面接线；
（4）全组共用的加载、错误、空状态和公共组件应承担什么职责、不承担什么职责。

2. 纳入范围

- 冷启动与会话恢复；
- 注册、登录、退出；
- 登录后进入地图/业务；
- 会话保持、会话过期、切换账号；
- 登录门禁与客户端主入口接线；
- 公共主题、加载/错误/空状态、公共组件；
- 两个核心流程的低保真导航图；
- 账号流程与公共界面的异常、边界和依赖问题。

3. 不纳入范围

- 地图渲染、真实 GPS 采集、定位权限的具体实现（赵冠钧）；
- 围栏、驻留、轨迹判定算法（对应后端/算法作者）；
- 答题题目抽取、答案校验、捕获结算（孙虹毅等业务接口作者）；
- 图鉴、背包、精灵详情的业务实现（对应业务页面作者）；
- 完整个人中心、主题切换、复杂动画（本阶段后置）；
- 全组测试设计、缺陷跟踪和测试报告（李宗晏）。

三、参与者和业务对象

1. 参与者

- 未登录用户：注册、登录；
- 已登录玩家：进入地图/业务、维持会话、退出、切换账号；
- 账号服务（支持参与者）：提供注册、登录、退出、当前用户接口；
- 演示者：课堂演示时使用演示模式；演示模式是否绕过真实登录，属于待确认项。

2. 业务对象

User / CurrentUser
- 含义：当前登录用户；
- 关键字段：userId、username、nickname；
- 归属：由闫昕提供；其他服务只调用 CurrentUser 入口，不各自复制一份用户对象。

Session
- 含义：一次登录产生的客户端会话；
- 关键字段：token、expiresAt、user；
- 状态：不存在、有效、已过期、已注销；
- 说明：token 是受保护请求的凭证；客户端不得用请求参数里的 userId 替代 token 身份。

SessionStore
- 含义：客户端会话的持久化入口；
- 职责：save(session)、load()、clear()；
- 约束：退出、切换账号、会话过期时都必须清理；保存方式（安全存储或普通存储）待确认。

AuthController
- 含义：账号交互的客户端控制器；
- 职责：接收登录/注册/退出请求，调用 AuthApi，更新 SessionStore，向页面暴露加载/错误/成功状态；
- 约束：依赖 AuthApi 接口注入，便于用 Fake AuthApi 做组件测试；不直接拼 HTTP 请求。

AuthApi
- 含义：账号接口的客户端契约；
- 候选方法：register、login、logout、me；
- 归属：网络层实现由冉昕霖负责；本分析只定义 AuthController 需要的调用契约和错误语义，不把实现写成余星晨的代码。

RequestId
- 含义：业务重试的请求唯一标识；
- 职责：首次点击时生成 UUID；网络重试必须复用同一个 requestId，不得在重试中偷偷重新生成；
- 归属：生成器由余星晨维护在 client/lib/core/request_id.dart；是否用于登录/注册，待与冉昕霖确认。

LoginPage / RegisterPage
- 含义：账号入口页面；
- 职责：输入、校验提示、提交中状态、失败提示、成功后跳转；
- 约束：不直接访问 HTTP；不直接决定服务端业务规则。

LoadingView / ErrorView / EmptyView
- 含义：公共状态组件；
- 职责：只负责显示加载、错误、空状态及重试入口；
- 约束：不承担登录判定、不承担权限判定、不承担业务结算。

3. 界面状态与业务状态的区别

界面状态：加载中、提交中、按钮禁用、错误横幅、空列表、键盘遮挡。
业务状态：未登录、已登录、已过期、已注销、用户名已存在、无权限、答案错误。

“按钮禁用”只能防止用户连续点击，不能代替服务端规则。例如重复注册的真正约束是服务端用户名唯一；会话是否有效必须由服务端校验，不能只信客户端保存的 expiresAt。

四、正常流程

1. 冷启动与会话恢复

（1）用户打开 App；
（2）入口读取 SessionStore；
（3）没有会话或会话已过期：进入登录页；
（4）会话存在且未过期：携带 token 请求 /users/me 或直接进入主界面，以服务端校验为准；
（5）校验通过：进入地图主界面；
（6）校验失败（401/过期）：清理本地会话和业务缓存，回登录页。

2. 注册

（1）未登录用户在登录页选择“注册”；
（2）进入注册页，输入用户名、密码、昵称；
（3）客户端做非空、长度、格式校验；
（4）提交注册请求；
（5）注册成功：按指南“注册成功后登录”，进入登录流程（自动登录或跳转登录页，待闫昕确认接口能力）；
（6）注册失败：保留输入，提示用户名冲突或其他错误。

3. 登录

（1）用户输入用户名和密码；
（2）客户端校验非空和格式，不合法时直接提示，不发请求；
（3）提交登录请求；
（4）服务端校验；
（5）成功：返回 token、expiresAt、user；
（6）客户端保存 Session，进入地图/原目标页；
（7）失败：统一提示“用户名或密码错误”，保留输入；网络失败提示重试并保留输入。

4. 进入业务

（1）入口判断 Session 是否存在且未过期；
（2）存在：进入地图主界面；
（3）不存在/过期：进入登录页；
（4）登录成功后进入地图；如果用户是从某个受保护页面被踢回登录，是否回到原页面，作为待确认项。

5. 会话保持

（1）受保护请求携带 Authorization: Bearer <token>；
（2）服务端校验 token 和过期时间；
（3）客户端不把 userId 作为身份凭证；
（4）收到 401 或明确的会话过期错误时，统一按“会话失效”处理。

6. 退出

（1）用户点击退出；
（2）客户端调用退出接口，使当前 token 失效；
（3）清理 SessionStore；
（4）清理挑战、收藏、页面缓存等业务缓存；
（5）回到登录页；
（6）退出接口网络失败时，本地会话仍应清理；服务端 token 失效尽力而为（待确认）。

7. 切换账号

（1）已登录用户选择切换账号；
（2）清理当前 Session；
（3）清理挑战、收藏、页面缓存；
（4）回到登录页；
（5）新账号登录后，所有查询按新身份重新校验，不能复用旧账号数据。

五、异常流程

异常场景 / 客户端行为 / 业务规则或来源

1. 用户名为空或格式错误
客户端在输入框旁提示，不发请求；保留其他输入。
规则来源：客户端校验；用户名长度/字符集待闫昕确认。

2. 密码为空或格式错误
客户端提示，不发请求；保留用户名。
规则来源：客户端校验；密码规则待闫昕确认。

3. 密码错误或账号不存在
显示同一条“用户名或密码错误”，不区分两者。
规则来源：本人指南第 18 页；服务端 40101。

4. 重复注册
提示“用户名已被占用”，保留已填输入，允许修改后重试。
规则来源：服务端用户名唯一约束；冲突错误码 40901（候选契约）。

5. 网络超时或断网
显示加载→错误提示→重试；保留输入；不把超时当成失败，也不当成成功。
规则来源：本人指南第 7、18 页；网络层由冉昕霖统一封装。

6. 会话过期
清理 SessionStore 和业务缓存，回到登录页，提示“登录已过期”；受保护请求由服务端拒绝，不能返回空成功。
规则来源：本人指南第 18 页。

7. 退出时网络失败
本地会话已清除，回到登录页；服务端 token 失效尽力而为，记录未完成项。
规则来源：本人指南第 18 页；具体行为待确认。

8. 切换账号后仍有旧页面缓存
清理挑战、收藏、页面缓存；每个查询按当前身份重新校验，不能显示上一个账号的数据。
规则来源：本人指南第 18 页。

9. 键盘弹出或小屏
表单可滚动，输入框和提交按钮不被键盘遮挡；在 360×800 和 412×915 视口下检查。
规则来源：本人指南第 7、18 页；UI 设计说明第 4 节。

10. 启动时本地有 token 但无网络
显示重试/离线提示，不直接把用户判定为未登录；是否允许只读缓存作为待确认项。
规则来源：本人指南第 7 页；需要产品/闫昕确认。

11. 客户端伪造 userId
服务端忽略请求参数中的 userId，身份只从 token 得出；客户端也不把 userId 当身份。
规则来源：本人指南第 18 页。

12. 重复点击登录/提交
提交中禁用按钮并显示加载；这是界面状态，服务端的唯一约束/幂等规则仍须存在。
规则来源：本人指南第 18 页；按钮禁用不能代替服务端规则。

13. 题目请求失败（答题捕获流程）
显示错误提示和重试/返回；不进入答题状态，不扣减机会。
规则来源：答题捕获流程分析；具体错误码待孙虹毅/冉昕霖确认。

14. 答题提交结果未知（超时/断网）
进入“结果待确认”，用同一 requestId 查询挑战状态或重试；不得重复结算，不得直接提示成功/失败。
规则来源：本人指南第 15、17 页；挑战状态待孙虹毅确认。

15. 定位/通知权限被拒（自习任务流程）
显示权限说明和设置引导，不启动任务；返回地图，不出现空白页或崩溃。
规则来源：本人指南第 7 页；具体权限文案待赵冠钧确认。

六、前置与后置条件

1. 注册
前置：应用已安装并可打开；用户未登录。
后置：账号创建成功；进入登录流程。
异常后置：不创建账号；保留输入；显示冲突或校验错误。

2. 登录
前置：账号已注册；客户端可访问账号服务。
后置：Session 保存成功；进入地图/业务。
异常后置：不保存 Session；保留输入；显示统一失败提示。

3. 进入业务
前置：Session 存在且服务端校验有效。
后置：进入地图主界面。
异常后置：清理无效 Session；回登录页。

4. 会话失效
前置：受保护请求返回 401 或明确过期错误。
后置：Session 和业务缓存清理完成；回登录页。
异常后置：清理失败时必须记录，不能继续显示旧账号业务数据。

5. 退出
前置：用户已登录。
后置：本地 Session 清理完成；服务端 token 失效（尽力）；回登录页。
异常后置：网络失败时本地仍清理；记录服务端失效未完成。

6. 切换账号
前置：用户已登录。
后置：旧 Session、挑战、收藏、页面缓存清理完成；新账号重新登录。
异常后置：清理不完整时禁止展示旧账号数据，记录缺陷。

7. 任务模式与精灵遭遇（导航层）
前置：用户已登录；已授予定位/通知权限；任务模式已开启。
后置：进入围栏并满足驻留条件后，地图出现精灵。
异常后置：权限拒绝、离开围栏、心跳断连时暂停/清零，不出现精灵。

8. 答题捕获与精灵收录（导航层）
前置：地图上存在可点击精灵；用户已登录。
后置：答对时写入图鉴/背包并返回地图；答错时提示逃跑/冷却；结果未知时进入待确认。
异常后置：网络失败/超时不重复结算；会话过期回登录并清理缓存。

- 间距：4 的整数倍，4/8/12/16/24/32dp；页面左右安全边距 16dp；
- 按钮圆角 8dp、卡片 12dp、浮层 16dp；可点击元素最小热区 48×48dp；
- 加载：显示 LoadingView，提交中禁用按钮，避免重复请求；
- 错误：显示 ErrorView，说明原因和下一步操作，保留用户输入；
- 空状态：显示 EmptyView，给出返回/重试等下一步操作；
- 适配视口：360×800dp 与 412×915dp；键盘弹出时表单可滚动，提交按钮不被遮挡。
详细规则见 analysis/diagrams/说明.txt 第三节。
